# Sistema de Login

Proyecto de una interfaz de inicio de sesión desarrollada con **HTML y CSS**.

## Funciones

El proyecto cuenta con las siguientes páginas:

* **Login:** correo y contraseña.
* **Registrar:** nombres, correo y contraseña.
* **Recuperar contraseña:** ingreso del correo y botón para enviar.
* **Cambiar contraseña:** correo, contraseña y repetición de contraseña.

## Diseño

La interfaz utiliza:

* HTML5
* CSS3
* Google Fonts (Poppins)
* Ionicons
* Animaciones y efectos de iluminación en color cian.
* Diseño responsive para diferentes tamaños de pantalla.

## Estructura del proyecto

```text
sistema-login/
│
├── index.html
├── registrar.html
├── recuperar.html
├── cambiar.html
└── style.css
```
